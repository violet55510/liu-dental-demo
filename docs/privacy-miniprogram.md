# 小程序《用户隐私保护指引》填写稿 · 齿记工具助手

> 用途：2026-11-27 第二次审核驳回（「正式上线必须签订隐私协议」）的整改材料。
> 微信后台入口：**设置 → 服务内容声明 → 用户隐私保护指引 → 去完善**（改现网版本）；
> 或 **管理 → 版本管理 → 提交审核 → 信息填写页**（改本次提审的开发版本）。
> 两个入口互不影响，只改了其中一个，另一个仍是空的——通常两个都要填。

## 一、`使用用户信息类型` 只勾两项

本项目代码里**没有调用任何隐私接口**（没有 `getPhoneNumber`、`getUserProfile`、`chooseAvatar`、`chooseImage`、`getLocation`、`getClipboardData`、`getSystemInfo` 等，已全量检索确认），所有个人信息都是**用户在表单里自己输入**的。所以按「实际处理了什么」来勾，不按「能不能勾」来勾。

| 选项 | 勾选 | 用途（后台会要求逐项填写） |
| --- | --- | --- |
| **手机号** | ✅ **勾** | 注册与登录账号、预约变更时与你联系 |
| **自定义** | ✅ **勾** | 就诊人姓名；预约与订单信息（科室、医师、时间、服务项目、备注） |
| 用户信息（微信昵称、头像等） | ❌ 不勾 | 没调用 `chooseAvatar` / `<input type="nickname">` / `getUserProfile`，也没让用户填微信昵称 |
| 位置信息 / 选择的位置信息 / 地址 | ❌ 不勾 | 没有定位、没有地图选点、没有收货地址，医师与门诊地址是展示文案 |
| 选中的照片或视频 / 选中的文件 / 相册（仅写入） | ❌ 不勾 | 没有上传图片、没有保存到相册 |
| 麦克风 / 摄像头 | ❌ 不勾 | 没有录音、没有拍照 |
| 通讯录（仅写入）/ 日历（仅写入） | ❌ 不勾 | 没有写联系人、没有写日程 |
| 剪切板 | ❌ 不勾 | 没有读写剪贴板（复制电话用的是页面展示，不是 `setClipboardData`） |
| 蓝牙 / 加速传感器 / 磁场传感器 / 方向传感器 / 陀螺仪传感器 | ❌ 不勾 | 都没有调用 |
| 设备信息 | ❌ 不勾 | 没有 `getSystemInfo` / `getDeviceInfo`，后台统计也没接 |
| 微信运动数据 / 发票信息 / 车牌号 / 身份证号码 / 邮箱 / 发布内容 / 操作日志 / 所关注账号 | ❌ 不勾 | 业务里都没有这些字段；医生账号用邮箱，但那是**医生在 Web 端**注册，不走小程序 |
| **订单信息** | ❌ 不勾 | 见下面第四节：本项目是**模拟支付**，没有调用任何支付接口，也没有支付账户、卡号、商户号 |

> 只勾「手机号」+「自定义」两项，是最小且如实的申报。**多勾不会加分，反而会被问「你的支付在哪里」「你的定位在哪里」。**

## 四、为什么「订单信息」不勾

后台「订单信息」这一类对应的是**微信支付 / 虚拟支付**相关接口采集的订单数据。本项目：

- 支付是**模拟**的：订单在服务端自己建（`orders` 表），只记 `appointment_id`、金额（由服务端按服务项目算）、`unpaid/paid/refunded` 状态；
- 没有调用 `wx.requestPayment`、没有商户号、没有 openid 绑定的支付单，也不采集卡号、二维码、支付密码。

所以「订单信息」不在申报范围内。**如果勾了，审核会顺着问「你的支付功能在哪里、类目资质呢」，反而多一轮。**

## 五、提审前三件事

1. **邮箱要真实可收信**：审核与用户都会用它联系你；写不存在的邮箱是常见驳回原因。
2. **名称、简介、页面文案不要再出现「诊所 / 门诊 / 医院 / 挂号平台」**等经营信息——上一轮已按要求改成「齿记工具助手」，本轮别回退。
3. **两个入口都填**：现网版本（设置 → 服务内容声明）与提审版本（版本管理 → 提交审核页）。提审页里改的只对本次开发版生效。

## 七、可选的加固（不影响本次提审，建议下一版做）

审核员判断「有没有隐私政策」时，除了看后台指引，也会看**小程序里能不能找到**。微信的指引本身会出现在「… → 更多资料」里，多数情况够用；如果想更稳，可以：

- 新增 `pages/privacy/privacy` 页面（静态文案，复用上面第六节），入口放在「我的」页底部；
- 注册页密码框下加一行勾选「我已阅读并同意《用户隐私保护指引》」，未勾选不允许提交；
- 页面数量从 9 变 10，需要同步改 `scripts/miniprogram-check.mjs` 的页数断言。

以上三项属于代码改动，确认要做再动手；本次审核驳回只需要填后台的隐私指引。
